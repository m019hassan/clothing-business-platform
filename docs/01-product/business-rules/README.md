# Business Rules Documentation

This directory contains business rule definitions for the clothing retail platform. Each file below defines specific operational constraints and decision criteria for business processes.

## File Contents
- [inventory.md]: Inventory movement and stock control rules
- [products.md]: Product listing and variant rules
- [orders.md]: Order processing and cancellation rules
- [payments.md]: Payment verification and dispute rules
- [factory.md]: Production planning rules
- [notifications.md]: Communication and alert rules
- [users.md]: Role-based access rules
- [discounts.md]: Pricing and promotional rules
