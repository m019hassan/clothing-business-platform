## Current phase
Sprint 0 - Project Foundation. This stage is documentation and project-structure preparation only.

## MVP summary
The MVP focuses on a practical foundation for catalog management, inventory, orders, payments, shipping, notifications, and role-based administration for a small clothing business.

## Architecture summary
The intended architecture is a modular monolith in Next.js with TypeScript, PostgreSQL, Prisma, and clear domain boundaries. The design remains intentionally simple for the MVP while supporting future growth, AI-assisted workflows, and controlled module extraction later if needed.
