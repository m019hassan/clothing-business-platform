# Project Context

## What this project is
This repository is the foundation for a scalable business platform supporting a small clothing business with production, inventory, retail, ecommerce, and future AI-assisted operations.

## Business context
The system must support multiple user types, role-based access control, catalog management, inventory, orders, payments, shipping, notifications, and potential future automation.

## Main users
- Business owner or manager
- Store and operations staff
- Factory staff
- Administrators
- Customers
- AI operators and assistants

## Project stage
The project is currently in Sprint 0 - Project Foundation. The work in this stage is documentation, structure, and governance rather than implementation.

## Business philosophy
Keep the system practical, auditable, and extensible. Start with a lean MVP and avoid premature complexity.
