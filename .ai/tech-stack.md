# Technology Stack

## Required technologies
- Next.js
- TypeScript
- React
- PostgreSQL
- Prisma ORM

## Expected supporting technologies
- Tailwind CSS
- Environment-based configuration
- Object storage for files and media
- Background jobs for asynchronous work where justified

## Optional future technologies
- Redis
- Docker
- Cloud deployment services
- Payment gateways
- Shipping providers
- Email and messaging integrations
- AI and LLM APIs

## Technologies requiring approval
Any new dependency or infrastructure choice should be justified by a clear need, documented tradeoff, and alignment with the project architecture.
