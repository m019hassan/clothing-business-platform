# Working Agreement for AI Agents

Before implementing anything, an AI agent must:
1. Read [PROJECT_MANIFEST.md](../PROJECT_MANIFEST.md).
2. Read [docs/README.md](../docs/README.md).
3. Read the relevant documentation for the task.
4. Review related architecture decisions.
5. Check the existing implementation before changing anything.
6. Explain the intended change clearly.
7. Implement only after the change is understood and aligned with the documented guidance.

## Expectations
- Do not silently change architecture.
- Do not bypass business rules or authorization.
- Keep the MVP simple and focused.
- Update documentation when architecture or business rules change.
