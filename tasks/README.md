# Task Management

This folder contains the project management structure for planned work.

## Workflow
- Backlog: ideas and future work that are not ready yet.
- Ready: work that is understood and prepared for execution.
- In Progress: active work currently being handled.
- Review: work that has been completed and is awaiting review.
- Done: completed work that is accepted and archived.

## Notes
No implementation tasks should be created in this stage. This folder is intended to structure future work in a consistent way.
