# Architectural Decision Records

This folder is intended to hold Architectural Decision Records (ADRs) for important project choices.

## Purpose
- Capture the reasoning behind major decisions.
- Preserve context for future contributors and AI agents.
- Reduce ambiguity when architecture evolves.

## Numbering convention
- Use a numeric prefix such as 0001, 0002, 0003, and so on.
- File names should follow the pattern: 0001-use-nextjs.md

## Current status
No ADRs have been created yet. This folder will be populated as decisions are made.
